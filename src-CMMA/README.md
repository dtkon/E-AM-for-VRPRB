# CMMA

This repo implements CMMA baseline in our paper: Deep Reinforcement Learning for the Vehicle Routing Problem with Route Balancing

## Dependencies
* Python>=3.8
* numpy
* hvwfg
* geatpy

## Usage

Run ```python ./src-CMMA/main.py -h``` for detailed help on the meaning of each argument.

Run ```python ./src-CMMA/parallel_start.py``` to run baseline datasets for our paper.
